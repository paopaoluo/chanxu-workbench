# 缠序 · 缠论结构研究台

网页研究工具：自动拉取在线日线，展示K线包含处理、分型、笔、线段/中枢代理与实验性买卖信号，并可用同一组数据做历史回测。

## 启动

优先双击桌面“缠序交易工作台”快捷方式，或项目中的 `打开缠序.cmd`。启动器会检查并恢复服务，然后打开网页。也可在 PowerShell 执行：

```powershell
Set-Location '<项目目录>'
.\启动.ps1
```

打开 [http://127.0.0.1:8765/](http://127.0.0.1:8765/)。服务只监听本机回环地址，不暴露给局域网。服务现由 Windows 任务计划程序 `Chanxu-Local-8765` 独立托管：登录自启、每分钟补查守护进程，服务退出约数秒恢复。关闭浏览器不停止服务。关机、休眠、退出登录时不能访问；登录触发已配置，本次没有为验证而重启电脑。要停用自启，先运行 `Disable-ScheduledTask -TaskName Chanxu-Local-8765` 和 `Stop-ScheduledTask -TaskName Chanxu-Local-8765`，再结束命令行路径属于本项目的 server.py 进程（不能只杀服务，否则会被恢复）。端口被占用时用 `启动.ps1 -Port 8766`，再打开相应端口地址。

## 行情

- 默认查询 `510300.SS` 沪深300 ETF；可填 Yahoo Finance 代码，例如 `510300.SS`、`000001.SZ`、`^SSEC`、`^HSI`、`AAPL`，或输入六位A股/ETF代码。
- 范围为 6 个月、1 年、2 年或 5 年，固定日线。数据经本机服务从 Yahoo Finance Chart API 获取，15 分钟缓存；可点“拉取行情”刷新。
- OHLC 使用未复权价格。A股按北京时间交易日历：15:00前排除当天日K，15:00后可纳入当天，但必须有行情源已更新到收盘的证据；未更新时标记等待，不把盘中K算作完整收盘。非A股沿用其数据完成度规则。数据状态分别标示当前来源/截止日/抓取时间/缓存年龄和最近请求状态。在线失败时现有数据不会被替换；没有可用行情时请重试、用合成示例或“CSV备用”。
- CSV备用要求列：`time,open,high,low,close,volume`，支持常见列名别名。页面也可下载当前K线CSV。

## 规则与回测

当前内置规则口径及边界见 [RULES.md](../RULES.md)。这是缠论研究代理，不是完整原典的唯一代码化：严格递归级别、特征序列线段、扩展/延伸边界及严格背驰尚未完成。图上的结构是全样本最终绘制，可能重绘；信号按当时逐前缀扫描生成，确认时间和冻结结构证据在图中查看。

回测为单一多头仓位；确认信号后的下一根K线开盘尝试成交，费用和滑点可调，按T+1及结构止损模拟；未平仓仓位按末根收盘估值。结果指标含区间收益、最大回撤、胜率、获利因子、平仓笔数与累计费用。参数只是研究默认值，任何修改后需重新运行回测。策略不连接券商、不下单。

## 自选股、中文名称和新B清单（2026-11-05）

### 自选股怎么用

1. 点左侧“自选股”，输入中文名（如皖通高速）或代码（600012），搜索后点“加入自选”。
2. 也可从当前图表标题旁或新B点清单的行内直接加入/取消自选。
3. 自选卡点“查看K线”拉取在线日线；点“移除”取消。新B清单的“查看K线”仍打开经SHA核验的扫描冻结数据，不与在线行情偷换。
4. 自选按添加顺序保存，最多200只；卡片展示为最新完整交易日新B优先，组内仍按添加顺序。保存在本机服务文件 `user-data/watchlist.json`，网页刷新和服务重启后保留；不是只存在某个浏览器，也没有云同步。首次为空，不替用户预填股票。
5. 文件损坏或保存失败会明确报错，保留原文件；其他页面同时修改时先重读并提示重试，不静默覆盖。

图表内标题显示“中文名称 · 代码”。名称来自本机证券目录（搜索处展示目录日期）和少量常用映射；查不到中文名时保留代码/供应商原名。中文显示只修改HTTP输出副本，不修改原始行情、冻结输入或算法。

### 新B点清单位置与排序

页面物理顺序为自选股、结构图、策略回测、新B点清单、规则说明；侧边导航“新B点清单”也位于“策略回测”下方。

默认排序：

1. **无异常标记**的股票在前，有标记在后；
2. 每组按 **目标日收盘价 × 目标日成交量（股）** 降序；
3. 同值按 **股票代码升序**。

第2项为成交额估算/流动性代理，不是交易所实际逐笔累计成交额。排序不代表买点强弱、胜率或预期收益，不给B1/B2/B3额外优先级。收藏、类型筛选和搜索不会重新排顺序。当前筛选范围仍为沪深主板非ST，排除科创板、创业板、北交所、ST；手动自选不改变每日扫描范围。

异常标记由既有扫描器决定：成交量为0、收盘价不高于结构失效参考、同日有S点、历史不足120根等；ST在正常股票池中已排除。清单日期、生成时间、覆盖率和缺失数独立展示，不把部分覆盖写成全市场完成。

接口：`GET /api/watchlist`、`POST /api/watchlist`、`GET /api/instruments?query=代码或中文名`。原引擎与信号计算不变。变更及验证证据见 `verification/watchlist-20261105/`；回退副本见 `backups/watchlist-20261105/`。回退代码时请保留用户自选数据。


## 自选每日观察（2026-11-05 10:43增强）

每只自选显示最新完整日K的收盘价与日期、最近一次确认的买卖信号及确认日；同日多个B/S分别展示。

**新B置顶规则：当前最新可计算交易日已确认B1/B2/B3的股票优先、高亮；普通股票在后，两组内部仍保持添加顺序。** 自选存储顺序和全市场新B清单的排序均不改变。新B不是预测，不以极值日替代确认日。

目标日来自服务端北京时间交易日历：15:00前看前一完整交易日；15:00后允许计算当天，但必须先取得当天完整收盘数据。过期缓存、缺失行情、日期未齐或时钟核验失败时保留旧值并明示日期/状态，不能继续亮“最新日新B”。同日B/S冲突或触及结构失效参考会单独提示。

页面打开、添加股票和手动刷新会读取固定近2年在线日K；同时最多读取2只。页面可见时每2分钟重试缺失/未完成/旧目标的记录，已完成的同日结果不会反复请求。收盘目标日改变会重新计算；本功能不是关掉网页仍运行的后台推送。概览请求不会切换你正在看的主图或影响回测结果。

行情和信号沿用原引擎；概览只存在页面内存，不向自选文件塞入会过期的行情字段。名称、币种、收盘日期均明确显示；非A股不套用A股目标日置顶规则。详细验证见verification/watch-monitor-20261105。

- `engine.js`、`daily_scan_engine.js`保持原字节和SHA，不修改包含、笔、中枢、背驰或B/S点判定，不做增量算法改写。
